# Void War 简体中文汉化补丁

为 **Void War 1.5.2b / Steam build 25669267** 制作的非官方简体中文补丁，适用于 Windows x64。包含中文菜单、系统提示、物品说明、剧情与对话，以及适配原作风格的中文宋体。安装器支持一键安装、原版备份和还原。

**[下载一键汉化 EXE](https://github.com/UNKNOWNTIMER/void-war-zh-cn/releases/latest/download/VoidWar_Chinese_Patch.exe)** · **[查看发行版本与校验值](https://github.com/UNKNOWNTIMER/void-war-zh-cn/releases/latest)**

这是资源差分补丁，需要你已拥有并安装对应版本的游戏。下载包不含游戏程序、完整 `data.win`、原版英文语言表或玩家存档。

完整图文操作说明见 [MANUAL.md](MANUAL.md)。本版适配已验证的 1.5.2b；1.5.3 beta / build 25749411 的资源不同，不受本包支持。

安装器采用暗金色哥特太空风格、原创舰船徽记与星尘动画。窗口顶部没有系统标题栏，右上角内嵌“×”关闭按钮，按住标题区域可以移动窗口。汉化作者 **UNKNOWNTIMER** 与适配版本只在中文游戏主菜单内显示署名，安装器和游戏其他页面不添加作者署名。

## 安装步骤

1. 先退出 Void War。首次使用游戏时，先正常启动一次并退出，让游戏建立自己的设置文件。
2. 下载发行页的 `VoidWar_Chinese_Patch.exe`，放在任意普通文件夹中。无需安装 Python，也无需手工复制多个文件。
3. 双击 EXE。安装器会尝试查找 Steam 游戏目录；未找到时，点击“选择目录”选择包含 `Void War.exe` 和 `data.win` 的 **Void War 文件夹**。
4. 点击“一键安装 / 更新汉化”，等待校验、备份和安装完成。只有写入受保护目录需要权限时，程序才会请求系统管理员权限。
5. 从 Steam 正常启动游戏。安装器会启用简体中文；需要检查语言时，进入 **设置 → 语言 → 简体中文**。

常见目录为 `C:\Program Files (x86)\Steam\steamapps\common\Void War`。游戏装在其他 Steam 库时，选择对应目录即可。

字体较大，首次加载时可能出现一段时间的黑屏，请等待主菜单完成载入。汉化器显示“汉化已安装并通过散列校验，可从 Steam 正常启动。”后即可关闭，玩游戏时无需运行汉化器。

## 还原与更新

重新打开同一个 EXE，选中游戏目录，点击“还原原版”。原版备份保存在游戏目录的 `_VoidWar_Chinese_Original`，请保留该目录。恢复只还原游戏资源和语言选项，不拿历史存档覆盖你后来取得的进度。

Steam 更新或“验证游戏文件完整性”可能覆盖汉化。补丁器会检查资源 SHA-256；如果游戏更新到了不同资源版本，它会停止，避免覆盖不匹配的游戏。请等对应版本补丁发布。不要为绕过检查而修改散列或替换未知文件。

已有旧版本地汉化且原版备份完整时，安装器可以接续受支持的版本；具体兼容资源以载荷清单为准。

## 汉化范围

- 三张原生语言表共 **12,872 条记录**：功能提示 726 条、界面及物品 3,798 条、剧情及对话 8,348 条。英文源原本为空的 592 个槽位保持为空。
- 全部 8,348 个剧情／对话键完成 AI 辅助逐句对照校订；相同原文及旧译按重复组复用校订决定，每个键都有覆盖记录。
- 人物和舰船背景、装备引文、历史公告等 693 个键完成专项精修，并统一派系、人物与装备术语。
- 发布前另逐键复核全部 726 条功能文本，以及其余 2,513 条非空界面文本，修正快捷键、系统机制、舰型、星区及成就条件中的旧机翻。
- 补充程序内硬编码提示、随机名称，以及原本画在贴图上的按钮和商店标题。
- 补齐独立战斗飘字中的“未中”“破舱”“免疫”“打断”“净化”“击杀”，并调整部署卡片和渗透状态文字的位置。
- 补齐毒气、眩晕、减速、传送等武器额外效果说明，以及部署至弱点、档案筛选和次数耗尽等程序直接生成的提示。
- 使用 OFL 许可的 **Noto Serif CJK SC Black** 中文字体；适配中文换行、主菜单字号、提示框高度及部分文字基线。

游戏艺术标题 **VOID WAR**、Steam／Discord 品牌、制作人员真实姓名、快捷键、罗马数字和程序动态变量保留原样。旧存档中玩家起的名字及既有角色历史姓名保留，不批量改名。

## 使用与验证边界

本项目由 AI 助手翻译、逐句精修和测试，未经过官方或专业人工译审。文本覆盖校验不等于把随机剧情的每一种分支都实际游玩了一遍；个别语气、双关和情境仍可能需要后续反馈修订。实际测试范围、字体检查和已知限制见 [验证记录](QUALITY.md)。

原游戏的西班牙语测试语言槽被改为简体中文。一部分硬编码文字和随机名称属于资源层修改，切回 English 时仍可能显示中文；需要完整原版语言资源时请使用“还原原版”。

为容纳原贴图标题的中文绘制，本版本停用了原作可选的 **F7 窗口尺寸调试叠层**；正常游戏界面、部署、召回、商店操作保留。补丁器未进行代码签名。

安装器不联网，不收集存档、账户或使用数据。它只修改清单内的游戏资源和设置中的语言字段，不修改自动存档或分数文件。
