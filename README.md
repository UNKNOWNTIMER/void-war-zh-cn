# Void War 简体中文汉化补丁

当前一键安装包适配 **Void War 1.5.3 beta / Steam build 25749411**，补丁版本 **2026.10.10.4**，适用于 Windows x64。包含中文菜单、装备说明、剧情与对话，修复引擎／传感器说明文字重叠、船员名位置和公告页滚动卡顿，并补齐独立脚本中的商人随机传闻。

**汉化补丁下载 / Patch Download：[VoidWar_Chinese_Patch.exe](https://github.com/UNKNOWNTIMER/void-war-zh-cn/releases/latest/download/VoidWar_Chinese_Patch.exe)**

这个固定地址继续用于本项目最新安装包。当前下载的是 **1.5.3 beta 专用包**；使用 **1.5.2b / build 25669267** 的玩家请下载 [历史稳定版安装包](https://github.com/UNKNOWNTIMER/void-war-zh-cn/releases/download/v2026.10.10.3/VoidWar_Chinese_Patch.exe)。两种游戏资源不相同，安装器会检查实际文件 SHA-256，拒绝不匹配的版本。

## 安装

1. 在 Steam 中切换到游戏的 **beta 分支**，更新到 **1.5.3 beta / build 25749411**。若之前安装了旧版汉化，先用对应旧安装包还原，再更新或验证游戏文件。
2. 启动游戏一次并正常退出，让游戏建立设置文件；安装时保持游戏关闭。
3. 下载并双击 `VoidWar_Chinese_Patch.exe`。无需 Python，也无需手工复制字体和资源。
4. 检查自动识别的目录；必要时点击“选择目录”，选择包含 `Void War.exe` 和 `data.win` 的 **Void War 游戏文件夹**。
5. 点击“一键安装 / 更新汉化”，等待显示安装完成且校验通过，然后从 Steam 正常启动游戏。首次中文字体载入可能较慢。

常见目录：`C:\Program Files (x86)\Steam\steamapps\common\Void War`。安装到其他 Steam 库时，选择相应游戏目录即可。写入受保护目录需要权限时，安装器才会请求 UAC。

## 本次更新

- 对照 1.5.3 beta 原始语言表，补齐并逐句修订 **27 个新增／变更键**，覆盖新增剧情、对话、舰型和界面说明。
- 当前三张语言表共 **12,874 条记录**：功能 726、界面 3,800、剧情／对话 8,348；原本为空的 592 个槽位保持为空。继承稳定版的逐句校订，检查键顺序、重复键、变量和英文残留。
- 另外补齐直接写在脚本中的 **156 条随机传闻**：通用 33、机械教团 51、鲜血教团 44、战神教团 28。修复商人闲聊显示 `ERROR: Unable to retrieve localized gossip text` 的问题，保留原有阵营选择、随机顺序和权重。
- 中文说明按实际字宽换行，修复引擎、传感器等提示框重叠；调整船员头像姓名的字号与基线，过长名字按框宽截断。
- 公告页缓存文本排版和高度，并跳过屏幕外的文字绘制，保留原有滚动范围和关闭方式。
- 补齐脚本拼接的闪避、充能、护盾、舱门及传感器加成说明。
- 使用 OFL 许可的 Noto Serif CJK SC Black 字体。检查实际译文使用的 **2,897 种字符**，OTF 与内嵌字体均无缺失字形。

## 还原和后续更新

再次打开同一 EXE，选择游戏目录，点击“还原原版”。本 beta 包的版本专用备份位于 `_VoidWar_Chinese_Original_1_5_3_beta`，请保留。旧稳定版的 `_VoidWar_Chinese_Original` 备份不与 beta 备份混用。

还原只恢复对应版本的游戏资源和当前设置中的语言字段，**不会用历史存档覆盖后续进度**。安装器不修改自动存档和分数文件。Steam 更新或验证文件可能覆盖补丁；若资源版本已改变，应等待对应适配包。

## 测试范围与说明

已实际启动游戏检查主菜单、公告连续上下滚动、制作人员页、引擎和传感器提示、船员名、Starfoil B 界面、商店购买与维修、部署和召回。新增／变更剧情对象通过临时测试选择器检查实际游戏渲染，商人随机闲聊另行复测；选择器不随补丁发布。具体样例、安装器测试和边界见 [QUALITY.md](QUALITY.md)。

本项目由 AI 助手完成翻译、校订和测试，未经过官方或专业人工译审。所有文本的静态覆盖检查不等于穷尽游玩每条随机剧情分支。

游戏艺术标题 VOID WAR、Steam／Discord 品牌、制作人员真实姓名、快捷键、型号、罗马数字和动态变量保留原样。旧存档里玩家起的名字和既有角色姓名不批量改名。原作的一个测试语言槽用于简体中文；部分资源层文字切回 English 后仍可能为中文，完整还原请使用安装器的“还原原版”。为中文绘制复用的可选 F7 窗口调试叠层与 F3 船员诊断叠层不再提供，正常玩法与操作保留。

安装器离线运行，无联网、账户、遥测或自动更新功能。下载包只包含差分、中文译文、字体和安装器，不包含完整游戏程序、完整 `data.win`、原版英文语言表或玩家存档。EXE 未进行代码签名。
